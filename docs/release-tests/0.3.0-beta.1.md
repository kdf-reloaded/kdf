# Tests passed before KDF Reloaded 0.3.0-beta.1

This page lists the tests that ran against the builds of this release before it was tagged: what
each one checked, on which build, and what came out of it. The tests ran from 2026-10-30 to
2026-11-01 on private networks with test wallets, plus one probe on the public network.

## Builds and conventions

**What SwapLab is.** SwapLab is the live test harness that runs Reloaded and reference nodes in isolated container stacks against real chains.

**Host.** One 256-core Linux host runs all nodes in containers.

**Reference nodes.** Komodo DeFi Framework 2.6.0-beta ("K", netid 8762, also accepts 6133) and GLEEC KDF 3.0.0-beta ("G", netid 6133, rejects 8762). These are the official release binaries, run unchanged; their behavior is reported as counts and outcomes only.

**Which rows count for the release.** The release is built from the development branch at the tag; its code is that of commit 9f0ec1c83 (dev after PR #190). Between 97f63a04d and 9f0ec1c83 only the arena limit at start-up (PR #190, with its specification PR #189) and documentation changed; that change got four checks of its own on 9f0ec1c83 (two configuration checks, the 40-minute soak and the idle smoke row). The commits after 9f0ec1c83 are documentation only (PR #192, this page, the CHANGELOG), which does not change the tested build.

Rows run on 00a8a0808 count for 97f63a04d: the two commits differ only by PR #182 and PR #184 (documentation) and PR #185 (peer exchange looks up hostnames that peers hand out). No lab row exercises PR #185, so it got three checks of its own on 97f63a04d. The swap, recovery and wallet rows (T1–T4, S2, S3', S9) ran on 99b289817. The commits merged after it change only the peer-to-peer layer and EVM fee handling, not the swap engine or the UTXO and shielded paths those rows exercise, so these rows count for the release too. Every row the later changes could affect (the EVM rows, S8, and the seed and relay rows) ran on 00a8a0808 or 97f63a04d.

**Short swap lock times.** Builds marked custom-swap-locktime use a test-only build feature that release builds never have. It lets a swap reach its refund time within minutes instead of hours.

**Conventions.** Times are CET. Dates are written `2026-10-31 18:22`. Durations are in min and s. Memory is in MB. Wallet roles: **D1** = maker W2 sells COIN for RIN, taker W1 pays RIN. **D2** = maker W1 sells RIN for COIN, taker W2 pays COIN. The second SwapLab lane uses W3/W4 in the same roles.

**Pass rule for swap rows.** The swap reaches Finished on both sides with both payments spent. Balance deltas equal amount minus fees. The evidence list is complete. **Pre-declared exceptions (N/A, not FAIL):** a G leg with ARRR (G rejects v6 ZHTLC transactions), a coin the reference binary does not support, Tron and Solana (off for this beta).

### Maker soak A/B/C — maker memory growth

**Setup**
- Build 97f63a04d; maker at debug level; 480 orders, 80 updates/s; 40 min load, 5 min idle, manual `malloc_trim`.
- A = default; B = `MALLOC_ARENA_MAX=2`; C = default allocator, maker pinned to 8 cores.

**What happened**
- A: RSS grew steadily while the live heap stayed flat; 778 allocator arenas held the free memory.
- B: with 2 arenas RSS stayed flat at the same update rate.
- C: with the maker pinned to 8 cores (32 threads, 36 arenas) RSS still grew; only 2 arenas stopped it.

**Result: allocator retention, not a leak.**

| Measure | A (default) | B (2 arenas) | C (8 cores) |
|---|---|---|---|
| RSS slope from minute 10 | *+1.17 MB/min* | *−0.04 MB/min* | *+1.02 MB/min* |
| RSS at minute 40 | 187 MB | 143 MB | 158 MB |
| Allocator arenas | 778–782 | 2 | 36 |
| Live heap (min 20–40) | 59–61 MB | 61 MB | 54–55 MB |
| Updates per second | 81.3 | 81.8 | 83.5 |

**Findings and history**
- The glibc arena cap is 8 × cores, so a 256-core host holds up to 2,048 arenas. Arm C shows that an 8-core pinning (36 arenas) does not remove the growth, so it is not specific to a many-core host.
- **Workaround:** with `MALLOC_ARENA_MAX=2` memory stayed flat at the same update rate (arm B).
