## Builds and conventions

The conventions below are carried over from 0.3.0-beta.1; confirm them before the campaign.

**What SwapLab is.** SwapLab is the live test harness that runs Reloaded and reference nodes in isolated container stacks against real chains.

**Host.** Pending.

**Reference nodes.** Komodo DeFi Framework 2.6.0-beta ("K", netid 8762, also accepts 6133) and GLEEC KDF 3.0.0-beta ("G", netid 6133, rejects 8762). These are the official release binaries, run unchanged; their behavior is reported as counts and outcomes only.

**Heads and binaries tested.**

| Build | Role | sha256 |
|---|---|---|
| pending | the release | pending |

**Which rows count for the release.** Pending.

**Short swap lock times.** Builds marked custom-swap-locktime use a test-only build feature that release builds never have. It lets a swap reach its refund time within minutes instead of hours.

**Conventions.** Times are CET. Dates are written `2026-10-31 18:22`. Durations are in min and s. Memory is in MB. Wallet roles: **D1** = maker W2 sells COIN for RIN, taker W1 pays RIN. **D2** = maker W1 sells RIN for COIN, taker W2 pays COIN. The second SwapLab lane uses W3/W4 in the same roles.

**Pass rule for swap rows.** The swap reaches Finished on both sides with both payments spent. Balance deltas equal amount minus fees. The evidence list is complete. **Pre-declared exceptions (N/A, not FAIL):** pending.
