# Tests passed before KDF Reloaded 0.4.1-beta.1

> **Status: final.** The lab rows below ran on the head `7afab797e` of the release branch work.
> The Windows desktop wallet round trip ran on the release branch build and passed.

This page lists the tests that ran against the builds of this release before it was tagged: what
each one checked, on which build, and what came out of it.

**Testing level.** 0.4.1-beta.1 is a patch release with one change: the order book no longer lists
ARRR or BC2 orders from nodes that cannot complete such a swap. The tests cover that change; the
full release matrix of 0.4.0-beta.1 is not repeated.

## Order book: hiding orders of nodes without the required capability

Setup for all rows: closed lab network, mainnet ARRR/RIN and BC2/DOGE on lab wallets; a Reloaded
observer, a Reloaded maker and a 2.6.0-beta maker connect to one seed (the relay); the 2.6.0-beta
maker sells ARRR at the better price. Run on the #447 head `7afab797e`. The code of the release is the same; the release commits
change only documents and the version.

| Row | Result | What is checked |
| --- | --- | --- |
| Order hiding, 2.6.0-beta relay | pass | `orderbook` and `best_orders` (by number and by volume) list only the Reloaded maker's ARRR order; the better-priced order of the 2.6.0-beta maker is not listed; the counts match |
| Order hiding, 3.x relay | not run, covered by CRD ch.59 §59.4B | a 3.x relay does not join the lab network; CRD ch.59 §59.4B records that a reference relay returns the protocol-information bytes unchanged |
| Requirement switched off | pass | with `require_v6_counterparty` false both orders are listed and the 2.6.0-beta order is the best one |
| `best_orders` refill | pass | a request for one order, and a volume request only the hidden order covers, both return the Reloaded maker's order |
| Early refusal | pass | `buy` with `match_by` naming only the 2.6.0-beta order is refused at once with "None of the orders named in match_by can be matched: ARRR requires a counterparty that declares tx_v6"; no order is left behind |
| BC2 | pass | the order of a 2.6.0-beta maker (no `sighash_suffix`) is hidden; with `require_suffix_counterparty` false both are listed |
| Reloaded relay, 2.6.0-beta observer | pass | through `best_orders` the 2.6.0-beta node sees both orders |
| Swap past a hidden order | pass | a taker that accepts any order swaps with the Reloaded maker to the end although the 2.6.0-beta maker has the better price |
| ARRR round trip in the Windows desktop wallet | pass | the desktop wallet on Windows ran the `kdf.exe` of the Staging Build of the release branch (run 44824108485, head `67e7a88e9`, sha256 `5fe8d927a6b28645930802e757257a8f4d7f5749eb4e7b291ad81a59d6e634f8`, confirmed on the running file; the node reported version `67e7a88`). The order book listed far fewer ARRR maker orders than before. As taker the wallet bought 1 ARRR for 0.002592812 LTC-segwit from a listed maker (swap `bc01d53b-c2f7-4e24-9028-54f813a929b4`, 2026-11-21 19:44 to 19:58 CET): the maker's ARRR payment and the taker's ARRR claim are both version-6 transactions, the LTC taker payment was spent by the maker, all events are success events and there is no error event |
