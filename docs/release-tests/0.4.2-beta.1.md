# Tests passed before KDF Reloaded 0.4.2-beta.1

> **Status: pending.** The rows below are planned; their results are entered when they have run.

This page lists the tests that ran against the builds of this release before it was tagged: what
each one checked, on which build, and what came out of it.

**Testing level.** 0.4.2-beta.1 is a patch release with one change, for ARRR only: a shielded spend
signs each note with the key of the ZIP-32 scope the note belongs to, so the change that a Pirate
wallet of the same seed keeps on its internal address can be spent, and `my_balance` shows only
what can be spent. The tests cover that change, a regression of the ARRR wallet, and a short smoke
test; the full release matrix of 0.4.0-beta.1 is not repeated.

## ARRR: change on the internal address of a Pirate wallet of the same seed

Setup: closed lab network, mainnet ARRR and RIN on lab wallets. The ARRR seed is also used in a
Pirate wallet, which has sent a payment and kept its change on its internal Sapling address. Two
KDF Reloaded nodes (R-R). Run on the head `af508ecee` of the release branch (the merge of #541).

| Row | Result | What is checked |
| --- | --- | --- |
| Balance and spendable amount, 0.4.1-beta.1 | pending | on 0.4.1-beta.1, `my_balance` and the amount a withdrawal can spend, for the same wallet (the reference point) |
| Balance and spendable amount, the hotfix | pending | on the hotfix build, `my_balance` equals the amount a withdrawal can spend |
| Withdrawal | pending | a withdrawal that needs the internal-address change is built, broadcast and mined |
| Swap payment | pending | an R-R ARRR/RIN swap in which the ARRR payment needs that change completes to the end |

## ARRR: wallet regression

Setup: as above, on the hotfix build.

| Row | Result | What is checked |
| --- | --- | --- |
| Deposit from a version-6 wallet | pending | a payment from a Pirate wallet that builds version-6 transactions to the node's `zs1` address is found and shown in the balance |
| Withdrawal to a `pirate1` address | pending | a withdrawal to a `pirate1` address pays the fee of 0.0001 ARRR (10,000 of the smallest unit) and is mined |
| Own change | pending | the change of that withdrawal, on the node's `zs1` address, is spendable in the next withdrawal |
